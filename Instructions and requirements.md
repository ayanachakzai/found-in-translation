# Instructions and requirements for project submission

## Step 1: Setup shared repo for group project
1. One member in the team should create a new repository using this template by clicking the green button that says **use this template** at the top right corner of the project page.
2. Once your repo is created the same member of the team should add the other group members as collaborators by clicking on:
    1. Settings > Collaborators > Add people 
    2. Then search for the other group members UAL student number to find their git.arts account and invite them to be a collaborator
    3. Repeat these steps for all members in the group

## Step 2: Add code files to this project 

Add any relevant code files to this project. If you have a lot of code files you should consider organising them into folders. Code files you should upload include:
- Create or curate your dataset (i.e. webscraping code or data cleaning code)
- Training or fine-tuning any models in the project
- All code required (including ComfyUI workflows) for the interactive project 
- Any other code developed for other additional project outcomes
- Code for alternative versions or earlier iterations of your project code (Make sure to explicitly name or number any earlier version of code that you want to share)

**WARNING:** Be mindful of the size of files before committing them to this repo. Files >100mb (such as model weights) cannot be committed to git.arts so should be uploaded to UAL onedrive and a link included in README.md. 

## Step 3: Upload dataset and video documentation of project demo to UAL onedrive

Designate one member of your group to upload both:
1. Your dataset as a `.zip` folder,
2. The video recording of your project demo (5 minutes max) as a `.mp4` 

To the UAL onedrive and include links to both of these in the `README.md` file. Make sure to create a shareable link that is available to **anyone with a UAL email**. To do this:
1. Right click on the file and select **share**
2. Click on the **link settings icon**
3. Select **people in University of the Arts London**
4. Click **Apply**
5. Click **Copy link**
6. Get a member of your team to check can access the file before adding it to the `README.md` file

## Step 4: Complete DATASHEET.md

Answer the question projects in DATASHEET.md to document your dataset. Answer each question as best as you can, though if a question is not applicable to the dataset you have created you respond with 'Not applicable because [give a reason]'

## Step 5: Complete README.md 

Complete all of the required information and sections in `README.md`which includes:
- Project name
- Group number
- Group members (Full names and student numbers)
- Link to dataset on UAL onedrive
- Link to video of project demo on UAL onedrive
- Overview of project
- Instructions for running project demo
- Additional project outcomes (if applicable)
- Supplementary materials  (if applicable)
- References
